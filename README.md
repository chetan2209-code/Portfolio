# Personal Portfolio Website #
A sleek, modern, and fully responsive personal portfolio website built with HTML, CSS, and JavaScript. Features a dark glassmorphism theme, smooth animation, and clean visual elements.

# Features #
- **Modern UI/UX**: Dark mode theme with glassmorphism effects and neon gradients.
- **Scroll Animation**: Smooth fade-in and slide animations using [AOS (Animate On Screen)]
- **Interactive Design**: Hover effects, typewriter subtitle, and interactive call-to-action buttons.
